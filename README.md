   - [ ] 간밤 나스닥 및 필라델피아 반도체 지수가 급락하지 않았는가?
   - [ ] 원/달러 환율이 1,360원 위로 급등하지 않고 안정적인가?
2. **2단계: 코스피 지수 위치 판별 (파생 수급)**
   - [ ] 코스피 종합 지수가 5,750~5,800pt 콜벽(저항선)에 머리를 맞대고 있지 않은가?
   - [ ] 5,450 ~ 5,500pt 지지선 부근에서 반등 양봉이 확인되었는가?
3. **3단계: 종목 수급 & 실적 팩트 확인**
   - [ ] 개인이 투매하고 **외국인과 기관(연기금·투신)이 동시에 순매수(쌍끌이)**하는 종목인가?
   - [ ] 최근 확정된 대형 수주나 분기 실적 서프라이즈 팩트가 있는가?
4. **4단계: 손익비 & 2% 리스크 통제 (가장 중요)**
   - [ ] 진입 전 손절가(Stop-Loss)를 차트 지지선으로 명확히 정했는가?
   - [ ] 목표가까지의 기대 수익이 손절폭의 최소 2배 이상(손익비 1:2 이상) 나오는가?
